## Productivity

- [Raycast](https://www.raycast.com) - Extensible launcher that replaces Spotlight, with clipboard history, snippets, and window management.
- [Alfred](https://www.alfredapp.com) - Keyboard-driven launcher with powerful custom workflows.
- [Things 3](https://culturedcode.com/things/) - Elegant, award-winning personal task manager.
- [Todoist](https://todoist.com) - Cross-platform to-do list with natural language input.
- [Fantastical](https://flexibits.com/fantastical) - Calendar and tasks app with natural language event creation.
- [Obsidian](https://obsidian.md) - Local-first Markdown knowledge base with backlinks and plugins.
- [Bear](https://bear.app) - Beautiful Markdown note-taking app for Apple devices.
- [Notion](https://www.notion.com) - All-in-one workspace for notes, docs, and databases.
- [Craft](https://www.craft.do) - Native document editor for structured notes and sharing.

## Developer Tools

- [Visual Studio Code](https://code.visualstudio.com) - Popular extensible code editor.
- [Zed](https://zed.dev) - High-performance, multiplayer code editor written in Rust.
- [Ghostty](https://ghostty.org) - Fast, native, GPU-accelerated terminal emulator.
- [iTerm2](https://iterm2.com) - Feature-rich terminal replacement for macOS.
- [Warp](https://www.warp.dev) - Modern terminal with AI and collaborative features.
- [Homebrew](https://brew.sh) - The missing package manager for macOS.
- [OrbStack](https://orbstack.dev) - Fast, lightweight way to run Docker containers and Linux VMs.
- [TablePlus](https://tableplus.com) - Native GUI client for relational and NoSQL databases.
- [Proxyman](https://proxyman.io) - Native HTTP(S) debugging proxy.
- [Tower](https://www.git-tower.com) - Powerful Git client.
- [Dash](https://kapeli.com/dash) - Offline API documentation browser and snippet manager.

## Utilities

- [Rectangle](https://rectangleapp.com) - Free, open-source window management with keyboard shortcuts.
- [LayoutKeeper](https://github.com/tumingke0/LayoutKeeper) - Restores window layouts and Spaces when you reconnect an external display.
- [CleanShot X](https://cleanshot.com) - Screenshot and screen recording tool with annotation.
- [Ice](https://github.com/jordanbaird/Ice) - Open-source menu bar manager to hide and organize icons.
- [Maccy](https://maccy.app) - Lightweight, open-source clipboard manager.
- [AltTab](https://alt-tab-macos.netlify.app) - Windows-style alt-tab window switcher with previews.
- [Stats](https://github.com/exelban/stats) - System monitor in your menu bar.
- [AppCleaner](https://freemacsoft.net/appcleaner/) - Thoroughly uninstall apps along with their leftover files.
- [Keka](https://www.keka.io) - File archiver supporting 7z, zip, rar, and more.
- [The Unarchiver](https://theunarchiver.com) - Unpack almost any archive format.
- [IINA](https://iina.io) - Modern, open-source media player for macOS.
